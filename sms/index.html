Where to send it

Use a Swiss mobile (+41 7x) if you can. Swiss operators accept our +41 sender, so the thread behaves the way a real owner will see it. Read the note below before testing on a French number.

Testing on a French mobile will look broken, and it is not. French operators forbid A2P delivery from a mobile long code, so Twilio reroutes the message through its French notification short code and the handset shows a 38xxx sender instead of our Swiss number. The reply therefore lands in a different thread from the one you texted. Swiss operators accept the +41 sender, so this does not happen for a real MoneyPark owner.

What happens after you trigger

  1. 1Maia opens the thread with the templated SMS: who she is, that the value moved, and one question. No link, no figure yet.
  2. 2You reply from your phone. Every reply reaches the agent, which replays the whole thread, so it remembers what was said.
  3. 3Maia routes on intent: she gives the figure, checks in on the property, offers the cockpit, hands over to an advisor, or closes.
  4. 4The link is appended by the flow, never written by the model, and only once the owner has clearly accepted.
  5. 5Reply STOP at any point. Opt-out is handled before the model is called, so it cannot be missed.
